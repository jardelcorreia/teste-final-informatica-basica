# Quiz de Informática Básica

Este é um simples quiz sobre conceitos básicos de informática, desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Perguntas de múltipla escolha.
- Barra de progresso para acompanhar o avanço.
- Feedback visual para respostas corretas e incorretas.
- Página de resultados com pontuação e mensagem.
- Botão para refazer o quiz.

## Como Executar

1. Clone este repositório:
   ```bash
   git clone <URL_DO_REPOSITORIO>
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd <NOME_DO_DIRETORIO>
   ```
3. Abra o arquivo `index.html` em seu navegador de preferência.

## Estrutura dos Arquivos

- `index.html`: Contém a estrutura HTML da página do quiz.
- `style.css`: Contém os estilos CSS para a aparência do quiz.
- `script.js`: Contém a lógica JavaScript para o funcionamento do quiz, incluindo as perguntas e o controle do jogo.
